# Reference implementation notes

The UI now presents the application as one human-guided growth operating system. Home prioritizes the next action and shows the profile context available to recommendations. Content Studio explains that the machine researches, chooses an angle and format, grounds claims, and asks for approval. Leads visibly distinguish known profile data from researched or unknown information. Analytics separates platform activity from CRM-derived business outcomes and does not fabricate reach or engagement.

The existing backend APIs and approval boundaries were preserved.
