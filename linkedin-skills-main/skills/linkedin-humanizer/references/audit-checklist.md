# Pre-Publish Audit Checklist

1. Hook Length: Opening sentence fits before mobile fold (<210 chars).
2. Line 1: No question openers (-34% engagement penalty).
3. Receipts: At least one odd-precision number with named referent.
4. AI Vocabulary: Paragraph density < 3 markers.
5. Rhythm: Natural sentence length variance; no forced burstiness.
6. CTA: Open-ended discussion prompt.
7. Post-script: Includes P.S. note for engagement lift.
8. External Links: No external URLs in main body.
